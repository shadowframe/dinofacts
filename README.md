## Installation

Clone das Repo auf deinen Rechner oder Server:

`git clone git@github.com:shadowframe/dinofacts.git`

`cd dinofacts`

Erstelle eine Virtuelle Python Umgebung

https://www.w3schools.com/python/python_virtualenv.asp

`python -m venv .venv`
